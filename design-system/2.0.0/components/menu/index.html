Menu

A trigger and the MenuList of commands it opens. It isn't modal: no focus trap, no scroll lock, nothing laid over the page, so the pointer passes over it and the page stays usable around it.

Source
Overview
Specs
Accessibility

A trigger and the MenuList of commands it opens. It isn't modal: no focus trap, no scroll lock, nothing laid over the page, so the pointer passes over it and the page stays usable around it. The list is placed position: fixed in the window, under the trigger, so a panel that scrolls or clips its content can't cut it off - but it stays inside the menu's own box in the DOM, so focus moving inside it is still focus inside the menu.

import { Menu, MenuDivider } from '@soroush.tech/design-system/Menu'
import { MenuItem } from '@soroush.tech/design-system/MenuItem'
import { Button } from '@soroush.tech/design-system/Button'

;<Menu trigger={<Button variant="text">main</Button>} onSelect={run}>
  <MenuItem value="new">New branch...</MenuItem>
  <MenuItem value="checkout" disabled note="Coming later">
    Checkout tag or revision...
  </MenuItem>
  <MenuDivider />
  <MenuItem value="rename">Rename...</MenuItem>
</Menu>
