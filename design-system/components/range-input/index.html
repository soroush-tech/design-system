RangeInput

A slider: one value on a range, or two or more thumbs for a range of values. Each thumb is a visually hidden native <input type="range">, so the keys (the arrows, Page, Home and End), assistive technology and forms work as the platform's; the pointer drags a thumb, touch included.

Every name is yours - each thumb's (getAriaLabel, or a FormLabel), and the text of its value (getAriaValueText) - so the slider carries no language of its own.

import { RangeInput } from '@soroush.tech/design-system/RangeInput'

// One thumb
;<RangeInput
  aria-label="Volume"
  value={volume}
  onChange={(_event, value) => setVolume(value as number)}
/>

// A range - one thumb for each value
;<RangeInput
  value={[20, 70]}
  onChange={(_event, value) => setRange(value as number[])}
  getAriaLabel={(index) => (index === 0 ? 'Least price' : 'Greatest price')}
  valueLabel="auto"
/>

Range With Aria Value Text

9:0017:00
const args: Partial<RangeInputProps> = { defaultValue: [9, 17], min: 0, max: 24, valueLabel: 'auto' }

<View paddingTop={4}>
  <RangeInput
    {...args}
    getAriaLabel={(index) => (index === 0 ? 'Opens at' : 'Closes at')}
    getAriaValueText={(value) => `${value}:00`}
    formatValueLabel={(value) => `${value}:00`}
  />
</View>

In Form Control

30

Loud or quiet.

const { error, disabled, size, color }: Partial<RangeInputProps> = { 'aria-label': 'Value', defaultValue: 40 }

<FormControl error={error} disabled={disabled} size={size} color={color}>
  <FormLabel>Volume</FormLabel>
  <RangeInput defaultValue={30} valueLabel="auto" />
  <FormHelperText>{error ? 'Too loud.' : 'Loud or quiet.'}</FormHelperText>
</FormControl>
