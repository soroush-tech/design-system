## @soroush.design/mcp@0.1.4

The component library is now `@soroush.design/react-components`, at `0.1.0`
([#114](https://github.com/soroush-tech/design-system/issues/114)), and an app imports it through the
platform umbrella `@soroush.design/react`
([#142](https://github.com/soroush-tech/design-system/issues/142)). Every component the server
describes is imported from the umbrella, where it was imported from `@soroush.tech/design-system`:

```ts
import { Card } from '@soroush.design/react/Card'
```

The install line and the import examples in the plugin's skills name the umbrella too. The
server's own name, its tools and their inputs (including the `design-system` package value), and
the ids of its documents do not change.

The summary of the Next.js App Router providers guide now reads "ThemeProvider plus the style
registry for the Next.js App Router". The docs the server serves are read from the component
library's docs, which changed for the new styling engine (the providers file and the setup guide
use it), so the served content changes with them
([#112](https://github.com/soroush-tech/design-system/issues/112)).

The documentation is now at https://docs.soroush.design: every `url` the server returns, the
`Docs:` line of its instructions and the package's `homepage` point there
([#148](https://github.com/soroush-tech/design-system/issues/148)).

The documentation pages have new addresses, and `url` follows them. A page's address is the path an
app imports it from in the `soroush.design` umbrella: `https://docs.soroush.design/react/Button/`
for `@soroush.design/react/Button`, `https://docs.soroush.design/react/Table/TableCell/` for the
member of a family, `https://docs.soroush.design/react/theme/` for the theme, and
`https://docs.soroush.design/react/markdown/Editor/` for the markdown library's components
([#149](https://github.com/soroush-tech/design-system/issues/149)). The `package` input of
`list_components` still takes `design-system` and `markdown`, and a component record still says
`design-system` in its `pkg`: nothing a client sends or reads besides `url` changes.
