## @soroush.tech/mcp@0.1.0

First release. An MCP server that gives AI coding tools first-class access to the
design system: the component inventory, every component README, and the theme token
contract, all generated from this repo's own sources at build time.

### Added

- Six tools: `list_components`, `get_component`, `get_tokens`, `list_docs`, `get_doc`,
  and `search_docs`. `get_component` serves a component's README, optionally sliced
  into `intro`, `api` (its props with token values and defaults), or `examples`.
- Two transports from one implementation. Run it locally over stdio with
  `npx -y @soroush.tech/mcp`, or connect to the hosted server:

  ```sh
  claude mcp add --transport http soroush https://mcp.soroush.tech/mcp
  ```

- Content generated from the repo rather than hand-maintained: component READMEs come
  from `packages/*/src/*/README.md` through the same registry and splitter the docs site
  uses, and the token contract is serialized from the live `baseTheme`, so a new scale
  appears with no extra step.
