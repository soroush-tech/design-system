## @soroush.design/mcp@0.1.3

Documentation release. The six tools, their inputs and their output are unchanged
([#87](https://github.com/soroush-tech/design-system/issues/87)).

### Changed

- **The README gives the hosted server's address for any MCP client,**
  `https://mcp.soroush.design/mcp`, before the Claude Code command.
- **The README names the house-style skill** that pairs with the server, installed for any coding
  agent with `npx skills add soroush-tech/design-system`.
- **`get_doc` returns the updated consumer guides.** The setup checklist, the layout kit and the
  brand theme no longer name private repositories or an internal app, and a test fails the build
  if the bundled content or the skill ever does again.
- **The skill works without the server.** Installed on its own, it reads its bundled
  `references/` and tells the user where to add the server, instead of calling tools that are
  not there. Its review checklist names the theme's real breakpoints.
