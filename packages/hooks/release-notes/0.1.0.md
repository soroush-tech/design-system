## @gild-ui/hooks@0.1.0

The React hooks of the Gild UI family that belong to no component and no theme, in a package
of their own ([#132](https://github.com/soroush-tech/design-system/issues/132),
[#133](https://github.com/soroush-tech/design-system/issues/133)). The component library is built
on them, and an app can use them with none of our components.

### What it offers

- **`useControlled`** - a value a control owns until its owner takes it over. Needs no browser.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#usecontrolled)
- **`useCopyToClipboard`** - copy text and show a `copied` flag for a while. Needs a browser (the
  Clipboard API), read only when `copy` is called.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#usecopytoclipboard)
- **`useDebounce`** - a value that follows another once it has stayed unchanged for a delay.
  Needs no browser.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#usedebounce)
- **`useDebouncedCallback`** - a function that runs your callback once, after a pause in its
  calls; a call still waiting at unmount never runs. Needs no browser.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#usedebouncedcallback)
- **`useEventCallback`** - a stable function identity that always calls the latest function.
  Needs no browser.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#useeventcallback)
- **`useMergedRefs`** - two refs merged into one stable ref callback. Needs no browser.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/hooks/README.md#usemergedrefs)
- **One entry point per hook, and a root.** `@gild-ui/hooks/useDebounce` loads that
  hook alone, and the root exports them all.
- **Server-safe, and shareable.** No hook reads a browser API when it is imported or rendered.
  The README says which ones need a browser when they are used, so the others can be shared with a
  React Native app.

### Packaging

- Peer: `react` `^19.2.8`. No dependencies.
- ESM and CJS builds with declarations, `sideEffects: false`, and a subpath export for each hook.
