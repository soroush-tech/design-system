## @soroush.tech/styled-system@6.0.2

`createShouldForwardProp` works in an app that has not installed the valid-attribute package
([#112](https://github.com/soroush-tech/design-system/issues/112)). No
public API changes.

### Packaging

- The valid-attribute package (`^1.4.0`) was an optional peer dependency, which apps got through
  the previous styling engine. It is now an ordinary dependency.
