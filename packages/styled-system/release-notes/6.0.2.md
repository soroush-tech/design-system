## @soroush.design/styled-system@6.0.2

`createShouldForwardProp` works in an app that has installed nothing for it, and forwards the
attributes React 19 added
([#112](https://github.com/soroush-tech/design-system/issues/112)). The breakpoint and query
helpers now come from `@soroush.design/core`
([#128](https://github.com/soroush-tech/design-system/issues/128)). No public API changes.

### Fixed

- **`fetchPriority`, `popover`, `inert` and the other attributes React 19 added are forwarded.**
  The list of valid attributes was too old to know them, so `createShouldForwardProp` dropped
  them.

### Changed

- **The breakpoint, media-query and container-query helpers live in `@soroush.design/core`.**
  `createMediaQuery`, `breakpointQueries`, `createMediaHelpers`, `createContainerQueries`,
  `containerKey`, `responsiveQueries` and their types are re-exported unchanged from `.` and
  `./core`, so an import of this package keeps working. The helpers are pure functions, and the
  other platforms of the family read the same ones.

### Packaging

- The package is published as `@soroush.design/styled-system` from this version.
- New dependency: `@soroush.design/core` (`^0.1.0`), imported and not bundled.
- The check for a valid attribute comes from `@umber-style/is-prop-valid` (`^0.3.0`), an
  ordinary dependency, imported by its named export so that the CommonJS build loads. The package
  used before was an optional peer dependency, which apps got through
  the previous styling engine and would now have had to install themselves.
