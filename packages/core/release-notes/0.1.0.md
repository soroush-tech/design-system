## @soroush.design/core@0.1.0

The package of the soroush.design family that holds what every platform shares and that needs no
framework. Its first content is the component catalog
([#127](https://github.com/soroush-tech/design-system/issues/127)).

### What it offers

- **The catalog.** Every component as data - its category, the subpath it is served from, what a
  freshly placed one is, its looks, the props a picker offers and their theme scales, how its
  node props are written - for tools that place and write components: a design tool's palette, a
  page's source writer, a generator. It is pure data, loads in plain Node with no DOM, and
  survives `JSON.stringify` unchanged.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/core/README.md#the-catalog)
- **No framework.** The package imports no React, React Native, Vue, DOM API or styling engine, and
  has no dependency. A test holds it to that, and reads the built files to prove it.
- **Each platform adds its own facts.** An entry names a `subpath`, not a package: a platform's
  library adds the package that serves it, as the React component library does with `module`.

### Packaging

- No dependencies and no peers.
- ESM and CJS builds with declarations: `@soroush.design/core/catalog`, and
  `@soroush.design/core/catalog/entries` for each component's entry and the value lists its props
  take.
