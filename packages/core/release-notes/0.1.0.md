## @soroush.design/core@0.1.0

The package of the soroush.design family that holds what every platform shares and that needs no
framework: the theme, the breakpoint helpers, pure utilities and the component catalog
([#127](https://github.com/soroush-tech/design-system/issues/127),
[#128](https://github.com/soroush-tech/design-system/issues/128),
[#129](https://github.com/soroush-tech/design-system/issues/129)).

### What it offers

- **The theme.** `baseTheme`, the token scales (`palette`, `space`, `radii`, `fontSizes`,
  `typography` as data, `breakpoints`, `layout`, `transitions`, `zOrder`, ...), the `Theme` types,
  `createTheme`, `themeDefault` and `spacing`. A platform library composes its own `Theme` on top
  of this one, so React, React Native and Vue read one theme. Every scale is an open interface that
  an app extends by declaration merging against `@soroush.design/core/theme`, or against the
  platform library that re-exports it.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/core/README.md#the-theme)
- **Breakpoint and container-query helpers.** `createMediaHelpers`, `createContainerQueries` and
  `withBreakpointHelpers` return `up`, `down`, `only`, `between` and `not` as range-syntax
  `@media` and `@container` rules. They are pure string functions, also re-exported by
  `@soroush.design/styled-system`.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/core/README.md#breakpoints)
- **Pure utilities.** `clamp`, `alpha`, `luminance`, `generateBoxShadow`, `getAnchorRel`,
  `getShapeRadius`, `getSurfaceRadius` and the step arithmetic of `precision`.
- **The catalog.** Every component as data - its category, the subpath it is served from, what a
  freshly placed one is, its looks, the props a picker offers and their theme scales, how its
  node props are written - for tools that place and write components: a design tool's palette, a
  page's source writer, a generator. It is pure data, loads in plain Node with no DOM, and
  survives `JSON.stringify` unchanged.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/core/README.md#the-catalog)
- **No framework.** The package imports no React, React Native, Vue, DOM API or styling engine, and
  has no dependency. A test holds it to that, and reads the built files to prove it.
- **Each platform adds its own facts.** An entry names a `subpath`, not a package: a platform's
  library adds the package that serves it, as the React component library does with `module`.

### Packaging

- No dependencies and no peers.
- ESM and CJS builds with declarations: `@soroush.design/core/theme`,
  `@soroush.design/core/breakpoints`, `@soroush.design/core/utils`, `@soroush.design/core/catalog`,
  and `@soroush.design/core/catalog/entries` for each component's entry and the value lists its
  props take.
