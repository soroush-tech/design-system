## @soroush.design/cli@0.1.0

First release. The command line of the design system, moved out of
`@soroush.tech/design-system` so that the component library carries no Node-only code
([#90](https://github.com/soroush-tech/design-system/issues/90)).
`npx @soroush.tech/design-system init` runs it, and so does `npx @soroush.design/cli init`.

### Added

- **`init` sets the design system up in a client-rendered React app**
  ([#79](https://github.com/soroush-tech/design-system/issues/79)), whatever builds it, in
  TypeScript or JavaScript: the themes, the providers with the base page styles, the root wrapped
  in `<Providers>`, and the install with the app's own package manager. It shows every change
  first and writes nothing before a yes; it needs a clean git tree, never overwrites a file, takes
  back every change when a write fails, and changes nothing on a second run. Run in a workspace's
  root, it sets up the one app in it.
- **`main(argv, io, designSystem)`**, the default export, for a package that runs this command
  line from a bin of its own. `@soroush.tech/design-system` does, passing its own `package.json`,
  so `init` installs exactly that version and checks React against its peer range.
