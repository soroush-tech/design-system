## @soroush.design/cli@0.2.0

### Added

- **`create [name]` starts a new app on the design system**
  ([#93](https://github.com/soroush-tech/design-system/issues/93)), in a new folder or an empty
  one, and never in a folder that holds anything. It asks for what it is not told - the name, the
  language, the default color scheme - shows every file and the install first, and writes nothing
  before a yes; `--yes`, `--dry-run`, `--framework`, `--ts`/`--js`, `--scheme` and `--no-git`
  answer ahead. It installs with the package manager that ran it, with no scripts, and runs
  `git init` with no commit unless the folder is already in a repository. When a write or the
  install fails, it takes the new app away.

### Changed

- The package entry re-exports `main` as its default export straight from where it is defined.
  Nothing changes for a caller: `import main from '@soroush.design/cli'` gets the same function.
- An option of one command given to the other is refused by name: `init --js` says `--js` is an
  option of `create`.
