## @soroush.design/cli@0.2.0

### Added

- **`create [name]` starts a new app on the design system**
  ([#93](https://github.com/soroush-tech/design-system/issues/93)), in a new folder or an empty
  one, and never in a folder that holds anything. It asks for what it is not told - the name and
  the title typed, then the language, the package manager, the default color scheme and the sample
  data pages picked with the arrow keys
  ([#101](https://github.com/soroush-tech/design-system/issues/101)) - shows every file and the
  install first, and writes nothing before a yes; `--yes`, `--dry-run`, `--title`, `--framework`,
  `--ts`/`--js`, `--pm`, `--scheme` and `--no-git` answer ahead, and so does `--sample-data`,
  below. The folder keeps the name as typed, and the package name is its lowercase form:
  `testApp` is the package `test-app`
  ([#100](https://github.com/soroush-tech/design-system/issues/100)). It installs with the package
  manager picked, the one that ran it unless another is, with no scripts, and runs `git init` with
  no commit unless the folder is already in a repository. When a write or the install fails, it
  takes the new app away.
- **The Vike starter** ([#94](https://github.com/soroush-tech/design-system/issues/94)), the
  default of `create`, in TypeScript or JavaScript: an isomorphic app, each page prerendered at
  build time with the styles it uses, so it is drawn styled before any script runs, then moving
  between pages in the browser with no reload. `<Providers>` lives in the app's `+Layout`, which
  holds a light and dark switch; the themes are `init`'s. It has a home page, a second page and a
  404 page, built from the design system's components and tokens only.
- **Sample data pages** ([#97](https://github.com/soroush-tech/design-system/issues/97)), with
  `--sample-data` or a yes to their question: `/items` lists six sample items and `/items/<id>`
  shows one, each page reading them in its `+data` at build time, with one page prerendered per
  item. A page reads its data with `useData()`. There is no data library to install.

### Changed

- The package entry re-exports `main` as its default export straight from where it is defined.
  Nothing changes for a caller: `import main from '@soroush.design/cli'` gets the same function.
- `Providers`, as `init` writes it, takes an optional `scheme` prop that picks the theme, the
  default scheme when it is left out. An app that renders `<Providers>` as before draws the same.
- An option of one command given to the other is refused by name: `init --js` says `--js` is an
  option of `create`.
- `--help` with a command shows that command's own options and examples, and so does a wrong
  option; with no command, it lists the commands.
