## @soroush.design/cli@0.3.0

The apps `create` starts use `@soroush.tech/design-system` 3 and its styling engine, UmberStyle,
and React 19.2 or later
([#112](https://github.com/soroush-tech/design-system/issues/112)).

### Changed

- **The Vike starter renders on the server with `@umber-style/server`.** `+onRenderHtml` calls
  `createStyleServer` from `@umber-style/server/create-instance` on the design system's
  `styleCache`, and the app's `package.json` lists `@umber-style/server`.
- **The Astro islands starter keeps the engine's style elements across page swaps.** The layout's
  `astro:before-swap` script keeps the elements the engine's cache writes into (`data-style`,
  `data-umber` and React's own) and its two markers, and moves the next page's styles into the
  head, except its base styles.
- Created apps use React 19.2 or later: they get the `react` and `react-dom` versions the CLI is
  tested with (`^19.3.1`).
- `init` checks your React against the design system's peer range, now `^19.2.8`: an app on
  React 18 is refused.

### Packaging

- The previous engine's server dev dependency is replaced by `@umber-style/server` `0.3.0`.
