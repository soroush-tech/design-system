## @soroush.design/cli@0.3.0

The apps `create` starts use `@gild-ui/react` `0.1.0`, its styling engine,
UmberStyle, and React 19.2 or later
([#112](https://github.com/soroush-tech/design-system/issues/112)).

### Changed

- **Apps import from `@gild-ui/react`.** `init` and `create` install it, with
  `@gild-ui/core`, which the theme (`createTheme`, `baseTheme`) is imported from, and write
  every other import as `@gild-ui/react/...`. `init` still recognises the files it wrote
  under the earlier markers. The command is `npx @soroush.design/cli`: the React package has no
  command of its own, so an app never installs the command line to run it.
- **The theme file follows the final shape.** `init` and `create` write the themes with
  `defineThemes(themes, {} satisfies ThemeComponents)`, the registration
  `declare module '@gild-ui/core/theme' { interface Register { themes: typeof themes } }`
  (TypeScript only) and `registerBaseTheme(themes.<scheme>)` with the theme the app starts in, the
  same object its provider gets, so server components are themed and the engine holds one theme.
- **The Vike starter renders on the server with `@gild-ui/react/server`.** `+onRenderHtml` takes
  `styleServer` from it, which extracts the styles of Gild UI's `styleCache`, so a new app has no
  `@umber-style/*` dependency of its own: it no longer gets `@umber-style/server`.
- **The Astro islands starter keeps the engine's style elements across page swaps.** The layout's
  `astro:before-swap` script keeps the elements the engine's cache writes into (`data-style`,
  `data-umber` and React's own) and its two markers, and moves the next page's styles into the
  head, except its base styles.
- Created apps use React 19.2 or later: they get the `react` and `react-dom` versions the CLI is
  tested with (`^19.3.1`).
- `init` checks your React against Gild UI's peer range, now `^19.2.8`: an app on
  React 18 is refused.
- The documentation is at https://gild-ui.soroush.design: the links in what `init` and `create` print
  and write (the setup guide, the fonts guide, the generated READMEs) and the package's `homepage`
  point there ([#148](https://github.com/soroush-tech/design-system/issues/148)).

### Packaging

- New apps no longer list `@umber-style/server`: the extraction is `@gild-ui/react/server`.
- The style-prop dependency of the apps it writes is `@soroush.tech/styled-system` `^6.0.3`, from
  npm: `@gild-ui/react` depends on it, so an app installs no copy of its own.
