# @soroush.design/cli

The command line of the [`@soroush.tech`](https://docs.soroush.tech) design system.

- **`create`** starts a new app: a working boilerplate on the design system, with its theme, its
  providers and a few pages in place, ready to build on.
- **`init`** sets the design system up in a React app you already have.

```sh
npx @soroush.design/cli create my-app
npx @soroush.design/cli init
```

Each shows every change first, and writes nothing until you say yes. `--help` after a command
lists its options.

**Documentation:** [docs.soroush.tech/cli](https://docs.soroush.tech/cli/) - every question and
option, the app `create` makes, and what `init` changes.
