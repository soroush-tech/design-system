# @soroush.design/cli

The command line of [Gild UI](https://gild-ui.soroush.design).

- **`create`** starts a new app: a working boilerplate on Gild UI, with its theme, its
  providers and a few pages in place, ready to build on.
- **`init`** sets Gild UI up in a React app you already have.

```sh
npx @soroush.design/cli create my-app
npx @soroush.design/cli init
```

Each shows every change first, and writes nothing until you say yes. `--help` after a command
lists its options.

**Documentation:** [gild-ui.soroush.design/cli](https://gild-ui.soroush.design/cli/) - every question and
option, the app `create` makes, and what `init` changes.
