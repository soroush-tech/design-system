## @soroush.design/react@0.1.0

The React platform of the soroush.design family, under one name: an app installs this package and
writes `@soroush.design/react/...` for everything it uses
([#135](https://github.com/soroush-tech/design-system/issues/135)).

### What it offers

- **Every entry point of the component library, under the same name.** `@soroush.design/react/Button`
  is `@soroush.design/react-components/Button`, and so are the other components, the root, `/theme`,
  `/catalog`, `/utils` and `/testing`. `/style` and `/engine` are the theme library's own:
  `@soroush.design/react/style` is `@soroush.design/react-theme/style`. Each entry is a re-export of one line, so
  an app loads only what it imports, as it does from the library.
- **The hooks and the markdown library, under a name of their own.**
  `@soroush.design/react/hooks/useDebounce` is `@soroush.design/react-hooks/useDebounce`, and
  `@soroush.design/react/markdown/Editor` is `@soroush.design/react-markdown/Editor`. Each library
  has a root of its own too: `@soroush.design/react/hooks` and `@soroush.design/react/markdown`.
- **One copy of each library.** The package imports the libraries and never bundles them, so
  an app has one theme and one set of styles, whichever of the two names its files import from.
- **Theme extension by either name.** An app adds colors, sizes and component variants with
  `declare module '@soroush.design/react/theme'`, or with the library's own name. Both reach
  `useTheme`, `styled`, `createTheme` and the props of every component.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/react-components/docs/theming.md)
- **Generated entry points.** `pnpm gen:umbrellas` writes the sources and the export map from the
  libraries the package points at, and CI fails when they drift.

### Packaging

- Peers: `react` and `react-dom` `^19.2.8`, both optional.
- Dependencies: `@soroush.design/react-components`, `@soroush.design/react-theme` and
  `@soroush.design/react-hooks`, installed once with this package.
- Optional peer: `@soroush.design/react-markdown` `^0.1.0`. It brings an editor and a diagram
  library, so an app that uses `@soroush.design/react/markdown` installs it itself, and one that
  does not installs none of them. Importing a `markdown` entry point without it fails with a
  module-not-found error.
- ESM and CJS builds with declarations, and a subpath export for every entry point.
