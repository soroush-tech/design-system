## @soroush.tech/markdown@1.2.3

Works with `@soroush.tech/design-system` 2: the peer range covers it, and the toolbar's dropdowns
are design-system `Select`s. ([#9](https://github.com/soroush-tech/design-system/issues/9))

### Changed

- The `Toolbar`'s heading, code-language and diagram dropdowns are `Select`s on the native path
  (`<Select native>`) instead of `NativeSelect`, following the design system's "always `Select`"
  guidance. They render the same native `<select>`, keep their accessible names
  (`Heading level`, `Code block language`, `Mermaid diagram type`) and still reset to their
  placeholder after each pick.

### Fixed

- **A link to a heading's section lands on it.** `Preview` gives every heading the id GitHub
  gives its anchor (`## Rows from data` is `#rows-from-data`, a repeat `#rows-from-data-1`), so
  a README's `#section` links work where it is rendered.

### Packaging

- Depends on `rehype-slug` `^6.0.0`, which names the headings.
- The `@soroush.tech/design-system` peer range is `^1.3.3 || ^2.0.0` (was `^1.3.3`), so
  design-system 2 consumers no longer get an unmet-peer warning.
  The range is now written out instead of derived from the workspace at publish time.
- **React 19.0 and up** - the `react` and `react-dom` peer range is `^19.0.0`; it had narrowed
  to `^19.2.8` through a dependency update, with nothing in the package needing more than 19.0.
- `homepage` is the package's docs, https://docs.soroush.tech/markdown/ (was
  https://soroush.tech/markdown).
- `repository` and `bugs` point at
  [soroush-tech/design-system](https://github.com/soroush-tech/design-system), where the package
  now lives, instead of soroush-tech/core. npm checks the provenance of a publish against
  `repository.url`, so a publish from this repo was refused while it named core. The README's
  badge, demo image and source links moved with it.
