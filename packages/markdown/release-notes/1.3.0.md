## @soroush.tech/markdown@1.3.0

Works with React 18 as well as 19
([#78](https://github.com/soroush-tech/design-system/issues/78)). No public API changes.

### Added

- **React 18 support.** `react` and `react-dom` peer ranges widen from `^19.0.0` to
  `^18.0.0 || ^19.0.0`, matching `@soroush.tech/design-system` 2.2.0. Every unit test passes on
  18.0.0, 18.3.1, 19.0.0 and 19.3.1, and CI runs them on 18.0.0 and 19.0.0.

### Packaging

- Raise the `mermaid` floor `^12.2.0` -> `^12.3.0`.
- Dev-dependency bumps: `@storybook/react-vite` and `storybook` `^10.6.3` -> `^10.6.7`,
  `@types/node` `^26.6.5` -> `^26.6.6`, `@vitest/coverage-v8` and `vitest` `^5.0.5` -> `^5.1.0`,
  `oxlint` `^1.89.0` -> `^1.93.0`, `tsdown` `^0.22.14` -> `^0.23.7`.
- `jsdom` `^29.1.1` -> `^31.0.0` for the unit tests. jsdom now computes styles as a browser
  does (lengths in px, transitions in seconds, media queries applied), and the tests expect those
  values.
