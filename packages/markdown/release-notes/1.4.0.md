## @soroush.tech/markdown@1.4.0

Works with `@soroush.design/react-components`, which needs React 19.2 or later
([#112](https://github.com/soroush-tech/design-system/issues/112)). Nothing else changes
for apps: no public API or behaviour changes.

### Packaging

- `react` and `react-dom` peer ranges narrow from `^18.0.0 || ^19.0.0` to `^19.2.8`.
- The component library peer is now `@soroush.design/react-components` `^0.1.0`. It was
  `@soroush.tech/design-system` `^1.3.3 || ^2.0.0`.
