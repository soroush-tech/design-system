## @soroush.tech/design-system@2.3.0

Starts a new app on the design system with `npx @soroush.tech/design-system create`
([#92](https://github.com/soroush-tech/design-system/issues/92)).

### Added

- **`npx @soroush.tech/design-system create my-app` starts a new app**, through
  [`@soroush.design/cli`](https://www.npmjs.com/package/@soroush.design/cli) 0.2.0: a Vike app,
  prerendered at build time with the styles each page uses in its HTML, then moving between pages
  with no reload, in TypeScript or JavaScript.
  It writes in a new or empty folder only, shows every file first and writes nothing before a yes,
  installs with the package manager you ran it with, and takes the app away when a write or the
  install fails. `<Providers>` lives in the app's `+Layout`, which holds a light and dark switch.
  With `--sample-data`, it adds a list of sample items and a page for each, which show how data
  gets onto a page ([#97](https://github.com/soroush-tech/design-system/issues/97)).

### Changed

- `Providers`, as `init` writes it, takes an optional `scheme` prop that picks the theme, the
  default scheme when it is left out. An app that renders `<Providers>` as before draws the same.
