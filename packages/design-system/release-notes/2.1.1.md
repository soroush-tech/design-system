## @soroush.tech/design-system@2.1.1

Maintenance release. Three fixes; no API changes.

### Fixed

- **A scrolling `Tabs` row no longer scrolls the page** - bringing the selected tab into view now
  scrolls the row itself, along its own axis. It used to scroll the whole page to the row as well,
  so a page with a scrolling `Tabs` in it opened scrolled down to it.

- **A `Menu` that is open on mount no longer scrolls the page** - the focus it puts on its first
  row (or the checked one) when it opens is set without scrolling, so a page with a menu open by
  default, or opened from code, opens at its top and not scrolled down to the menu.

- **A `Sidebar` rail keeps its own width** - its `layout` (`inline` or `stacked`) was also read as the
  page layout grid, which gave the rail `width: 100%` and inline padding from the first breakpoint
  up. A stacked rail in a wide window took all the room and left its panel a sliver; it is now
  `stackedWidth` wide, and an inline one `expandedWidth` or `collapsedWidth`, at every size.
