## @soroush.tech/design-system@2.0.0

The theme holds the page's layout system - Material 3's window classes as breakpoints, and the
layout tokens per class - so an app and the design studio work from the same values. Everything
responsive is CSS: pages work with JavaScript off.
([#344](https://github.com/soroush-tech/core/issues/344))

### Added

- **`theme.breakpoints`** - each key a range, from its value until the next: `xs` 0-599px
  (compact, the base), `sm` 600-839 (medium), `md` 840-1199 (expanded), `lg` 1200-1599 (large),
  `xl` 1600+ (extra-large). Responsive props use them by name (`p={{ xs: 2, md: 4 }}`), by
  position (`p={[2, 3, 4]}`) or as container queries (`cqSm`). `BreakpointOverrides` adds,
  renames or removes breakpoints with type safety.
  [docs](https://github.com/soroush-tech/core/blob/main/packages/design-system/docs/theming.md#breakpoints-and-layout)
- **Query helpers** - `theme.breakpoints.up` / `down` / `only` / `between` / `not` and
  `theme.breakpoints.containerQueries`, rebuilt from the theme's own sizes by `createTheme` and
  `ThemeProvider`; plain `up`, `down`, `only`, `between`, `not` and `containerQueries` exports
  for `baseTheme`, and `withBreakpointHelpers` for a scale of your own.
- **`theme.layout`** - layout tokens per window class: `content` (columns 1-16, margin and gutter
  as `theme.space` keys, fluid or fixed with `maxWidth`), `panels` (`start` / `end`, each
  `inline`, `overlay`, `collapsed` or `hidden` with `width` and `railWidth`) and `bars` (a 64px
  top bar on every class). `baseTheme` uses 4 / 8 / 12 / 12 / 12 columns, the start panel as a
  72px rail from `sm` and inline at `xl`, the end panel as an overlay at `md` and `lg` and inline
  at `xl`.
- **`layout` prop on `Grid` and `Flex`** - `<Grid layout>` lays the theme's column grid out per
  class (column tracks on a Grid, a wrapping row on a Flex) with `--layout-columns` /
  `--layout-gutter` for children; `layout={{ lg: { columns: 16 } }}` replaces it at `lg` only.
  Explicit grid, flexbox, gap and padding props still win.
- **`span` on `View`** - how many layout-grid columns an element takes (`span={{ xs: 4, md: 6 }}`),
  in a `Grid layout` or a `Flex layout`; every `View`-based component takes it.

### BREAKING CHANGES

- **Responsive props switch at the window classes.** Without `theme.breakpoints`, array props
  used styled-system's defaults (40em / 52em / 64em). A theme built from `baseTheme` now has
  `xs` 0, `sm` 600, `md` 840, `lg` 1200 and `xl` 1600px: `display={['none', 'none', 'block']}`
  shows from 840px instead of 832px, and a four-value array reaches `lg`. Migrate: move each call
  site to named keys (`{ xs: 'none', lg: 'block' }`) at the class you mean.
- **`_` is no longer a responsive key** - use `xs`, the base class.
- **Generated queries are range syntax** (`@media (width >= 840px)`), through
  `@soroush.tech/styled-system`.
- **`Theme` requires `breakpoints` and `layout`.** A theme written out by hand as a full `Theme`
  object no longer typechecks. Migrate: build it with `createTheme(baseTheme, ...)`.

### Packaging

- Depends on `@soroush.tech/styled-system` `^6.0.0` (range-syntax queries, helpers, container
  queries, the layout grid).
