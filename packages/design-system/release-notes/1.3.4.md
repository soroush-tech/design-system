## @soroush.tech/design-system@1.3.4

Documentation only. No code and no API changes - the published bundle is identical to 1.3.3.

### Added

- Every component now owns its documentation page: `<Name>.mdx` sits beside the component's
  `README.md` and drives that component's page on docs.soroush.tech. The page renders the
  README's intro followed by every story in `<Name>.stories.tsx` as a live, editable demo.
- The page is required - a component without one fails the docs build.
