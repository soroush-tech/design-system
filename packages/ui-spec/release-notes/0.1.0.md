## @soroush.tech/ui-spec@0.1.0

First release. The generative-UI spec for the design system: one JSON shape an agent writes and
a tool validates, built on A2UI v1.0 with that protocol left unchanged.

### Added

- **`composeCatalog`** - builds an A2UI v1.0 catalog from an app's components, with the core
  added: the `When` component and eight functions (`setValue`, `lookup`, `sumField`, `divide`,
  `round`, `ceil`, `max`, `select`).
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/ui-spec/README.md#catalogs)
- **`When`** - a component that renders one child chosen by a value. A2UI v1.0 has no
  conditional rendering, so this is how a surface shows a skeleton, an error and the content.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/ui-spec/README.md#showing-a-skeleton-an-error-and-the-content)
- **`applyTheme`** - specializes a catalog for one app's theme, so a token key or a Button
  variant the app added through its theme is accepted.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/ui-spec/README.md#props-that-come-from-the-theme)
- **`behaviorSchema`** - the JSON Schema of a behavior document, version 0.1: page params,
  queries and mutations, derived values, triggers and the document head.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/ui-spec/README.md#the-behavior-document)
- **`validateCatalog`**, **`validateSurface`**, **`validateBehavior`** - validators that return
  findings as data and never throw. Each finding carries a code from a closed set, a JSON
  Pointer into the document, and a message.
  [docs](https://github.com/soroush-tech/design-system/blob/main/packages/ui-spec/README.md#validating)

### Packaging

- Depends on `ajv` `^8.18.0` and `ajv-formats` `^3.0.1`. The engine was chosen by running the
  156 conformance cases of the A2UI specification: `ajv` agrees with all of them.
- Bundles the A2UI v1.0 JSON schemas and basic catalog, unmodified, from commit `46ecc2d0` of
  the A2UI repository. They are licensed under the Apache License, Version 2.0; the license and
  a note of the source ship in `vendor/a2ui/v1_0/`.
